# History Voice

History Voice est une application mobile (Android/iOS) qui génère des histoires personnalisées pour enfants et adultes, puis les raconte à voix haute.

## Ce que fait l'app

- L'utilisateur choisit quelques paramètres (âge, genre de l'histoire, moment de la journée, durée souhaitée...)
- Une histoire unique est générée par intelligence artificielle à partir de ces choix
- L'histoire est ensuite narrée en audio grâce à une voix de synthèse naturelle, comme un livre audio
- Disponible en 10 langues : français, anglais, espagnol, portugais, italien, néerlandais, allemand, arabe, turc, polonais

## Modèle économique

- Connexion via compte Google
- Système de crédits (temps de génération) achetables en pack
- Un pack premium acheté offre une période sans publicité ; les utilisateurs gratuits voient des publicités non personnalisées (bandeau + interstitiel)

## Public

Application à usage familial, conçue pour être adaptée aux enfants (contenu classé G, publicités non personnalisées, aucune collecte de données de localisation ou de contacts).
